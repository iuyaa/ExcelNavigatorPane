Excel Navigator {VERSION} 内部试用版

适用环境：Windows 10/11 桌面版 Microsoft Excel（x86 或 x64）。
不支持 Mac、网页版 Excel 或 ARM64 原生 Excel。用户无需 Visual Studio。
对已能自动加载此插件的 WPS 表格环境增加兼容修复；64 位 Windows 同时注册 32/64 位加载项，尚未适配只有 WPS 的电脑。

安装：
1. 保存工作并关闭所有 Excel 和 WPS 表格窗口。
2. 如果安装过旧 ClickOnce 版，先到“控制面板 → 程序和功能”卸载 ExcelNavigatorPane。
   开发机遇到 bin/Debug 或 bin/Release 注册时，可在安装器中确认备份并移除；不删除项目文件。其他冲突仍需维护人员处理。
3. 双击 ExcelNavigator-Setup-{VERSION}.exe，安装器按 Windows 位数选择内置 MSI；64 位 Windows 同时支持 32/64 位 Excel/WPS。
4. 安装需要管理员授权；缺少 .NET Framework 4.8 或 VSTO Runtime 时由微软引导程序联网下载。
5. 重新打开 Excel，在“文件 → 选项 → 加载项 → COM 加载项”中查看 Excel Navigator。

安装到 Program Files，使用本地 VSTO 加载，不再从网址安装 ClickOnce。
无需手工导入内部根证书。Windows 仍可能提示未知发布者；公司策略限制时请联系 IT。
安装器不会自动关闭 Excel，不会导入根证书或关闭 Office 安全保护。
如果安装前仍有 Excel/WPS 进程，EXE 提示先保存工作并关闭，点击“重试”重新检测；也可以取消安装。旧的当前用户加载项注册按上述规则处理。

更新：
更新渠道：{CHANNEL}。GitHub 渠道从公开 GitHub Release 更新；oneview 渠道从 OneView 对象存储更新。
在导航栏工作簿菜单中选择“检查更新”，发现新版后选择是否下载并打开安装程序。
自动保存到系统临时目录的 ExcelNavigatorPane\Updates 子目录（通常为 %TEMP%\ExcelNavigatorPane\Updates），无需另存为。
清单签名与 EXE 哈希验证通过后才保留安装包；下载失败不替换原有文件。
下载校验完成后自动打开新版 EXE；安装器提示先保存工作、关闭所有 Excel/WPS，再点击“重试”继续，也可以取消。无需再卸载 MSI 版。
自动打开失败会提示文件路径供手动运行。不在启动时自动检查更新，不强制关闭或重启 Excel/WPS。
旧 ClickOnce 版需要首次手工迁移到本安装包，之后使用此更新方式。

卸载：在 Windows“控制面板 → 程序和功能”中找到 Excel Navigator 并卸载。
安装源保存在 %LOCALAPPDATA%\ExcelNavigatorPane\Installer\版本号，供修复使用。
卸载后可自行清理安装缓存。

IT 手动部署可使用对应 Windows 位数的 MSI，必须先准备运行环境、关闭 Excel并移除旧 ClickOnce 注册。
同一版本不要混用 x86/x64 MSI，不支持降级。

本包已通过构建、EXE 解包哈希、MSI 注册/升级规则和签名更新清单校验。
WPS 修复：同一主窗口共用导航栏、使用宿主接口切换工作簿、按实际打开窗口清理；Excel/WPS 单张表取消隐藏后自动切换过去。
WPS 编辑中切换暂不支持；真实 WPS 点击、关闭工作簿及编辑状态回归仍待验收（NOT_RUN）。
无开发环境电脑上的首次安装、加载、真实升级/回滚/卸载尚未验收（NOT_RUN）。
若尚未上传更新入口清单，“检查更新”会提示失败，不影响插件使用。
建议先在独立电脑验收；失败时记录错误全文、Windows/Excel 版本及 Excel 位数。

开发注册迁移备份：HKCU\Software\ExcelNavigatorPane\RegistrationBackups，具体路径记在安装日志中。若迁移后取消或安装失败，备份仍保留，可由维护人员恢复；无需删除项目目录。
